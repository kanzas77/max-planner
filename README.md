# MAX — Планировщик задач

Персональный планировщик задач и заметок, работающий полностью в браузере.
Без серверов. Без регистрации. Без подписок. Без интернета.

## ✨ Возможности

### 📋 Задачи
- Создание задач с названием и описанием
- 3 уровня приоритета (низкий / средний / высокий)
- 6 категорий (Работа, Личное, Учёба, Здоровье, Дом, Другое)
- Мгновенный поиск и фильтрация
- Отметка выполнения
- Прогресс-бар

### 📝 Заметки
- Создание цветных заметок
- 6 цветовых вариантов
- Адаптивная сетка

### 📊 Статистика
- Общая сводка по задачам
- Прогресс по категориям
- Разбивка по приоритетам

### 💾 Резервное копирование
- Экспорт данных в JSON-файл
- Импорт данных из файла
- Перенос между устройствами

## 🎯 Преимущества

| Преимущество | Описание |
|---|---|
| 🔒 Приватность | Данные хранятся только на вашем устройстве |
| ⚡ Скорость | Мгновенный отклик, нет HTTP-запросов |
| 📵 Офлайн | Работает без интернета |
| 💰 Бесплатно | Никаких подписок и скрытых платежей |
| 🚫 Без регистрации | Не нужен email, телефон, аккаунт |
| 💾 Контроль данных | Экспорт/импорт в один клик |
